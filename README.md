# ecomm-app-native 🛍️

A modern, high-performance E-Commerce mobile application built with React Native and Expo.

## Features

- **Product Showcase**: Browse products across various categories with high-quality images and pricing.
- **Search & Filter**: Search products dynamically and filter by categories.
- **Product Details**: View detailed product specifications, reviews, and images.
- **Cart & Wishlist**: Manage cart items with quantity controls and save favorite items to wishlist.
- **Seamless Checkout**: Interactive checkout modal with order summary and payment confirmation.
- **Cross-Platform**: Supports iOS, Android, and Web using Expo.

## Tech Stack

- **Framework**: [Expo](https://expo.dev) & React Native
- **Navigation**: Expo Router (File-based routing)
- **Icons**: Expo Vector Icons (Ionicons)
- **Styling**: Native StyleSheet & responsive layout design
- **State Management**: React Context API

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn
- Expo Go app on your physical device (iOS or Android) or an emulator

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/TayyabFrank/ecomm-app-native.git
   cd ecomm-app-native
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npx expo start
   ```

4. Run on your desired platform:
   - Press `a` for Android Emulator
   - Press `i` for iOS Simulator
   - Press `w` for Web
   - Scan the QR code with Expo Go on your mobile device
